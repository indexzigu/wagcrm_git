# Handoff 파일 규약 — 인덱스 보드(PROJECT_MASTER.md)의 상세면

- **파일명:** `pr-<번호>-<슬러그>.md`. PR 생성 전이면 `<브랜치슬러그>.md`로
  만들고 번호 확정 시 rename한다.
- **소유권:** 항목을 만든 세션(레인)이 소유한다. 타 세션은 상태 줄 갱신 외
  수정 금지.
- **보드 연결:** 파일 생성과 동시에 `PROJECT_MASTER.md`에 1줄 추가한다
  (상태 · 제목+PR# · 다음 게이트 · 이 파일 링크). 보드에는 서사를 쓰지
  않는다 — 상세는 전부 이 파일에.
- **수명주기:** 착지+검증 완료 → `PROJECT_LOG.md`에 요약 1줄 → 이 파일을
  `docs/archive/handoff/`로 이동 → 보드에서 줄 제거.
- **데이터(모드 L):** 이 디렉터리는 README를 제외하고 git 미추적(로컬
  전용)이다 — 실명·실측치 기록 가능. 단 git 백업이 없으므로 영속 가치가
  있는 결정은 착지 시 코드·계약 테스트·`docs/agents/` 모듈로 환원한다.
  워크트리 세션은 메인 레포 루트(`git worktree list` 첫 항목)의
  `docs/handoff/`에 쓴다 — 자기 워크트리 사본에 쓰면 다른 세션이 못 본다.

## 템플릿

```md
# <제목> (PR #NN · 브랜치 <이름>)

- 상태: 진행중 | PR 대기 | 머지됨·검증 대기 | 블록(<사유>)
- 다음 게이트: <누가> <무엇을>
- 한 줄 정의: <이 작업이 무엇인지 모호함 없이>
- 필독 경로: <파일> — <왜 읽어야 하는지>
- 검증: <수행한 검증과 결과 요약>
- 함정/제약: <다음 세션이 걸려 넘어질 것>
- 미결(오너): <오너만 결정할 수 있는 것>
```
